OpenHCS

Open-source analysis software for high-content microscopy: plates with many wells, sites, channels, Z planes, or time points. Pipelines are compiled and checked against the selected data before they run. The same pipeline can be edited in the desktop app, as Python, imported from a CellProfiler .cppipe, or built by a local agent over MCP.

Design

  1. Validated before execution.

    The pipeline is compiled against your selected wells, sites, channels, and planes before any work starts.

  2. One pipeline representation.

    The GUI, generated Python, and the MCP server edit the same typed object; there is no conversion between formats.

  3. One declaration per fact.

    Each fact lives on the declaration that owns it; every list is derived from those. How.

  4. Errors, not fallbacks.

    Unsupported input stops with an error naming the cause; nothing is silently substituted.

  5. Published evidence.

    Figures have checksum records; the agent run below is published uncut with its logs.

  6. MIT licensed.

    The general parts are separate libraries.

Installation

Desktop installers No Python needed

Download for WindowsDownload and run — no ZIP to extract Download for macOSOpen the DMG, then open OpenHCS Installer

CPU-only installers that include CellProfiler compatibility, local MCP, Napari, Fiji, and Bio-Formats. GPU libraries are optional and not included. Fiji downloads Java on first use. The latest complete GitHub release may trail PyPI. The Windows installer is unsigned and the macOS installer is not notarized; your OS will ask you to confirm.
