For imaging scientists and research software teams

Check the whole plate before you run it.

Open-source analysis for high-content microscopy: many wells, sites, channels, Z planes, or time points, all analysed the same way. OpenHCS checks your pipeline against the plate before it runs, so a bad setting fails in a second, not after a night of processing. Edit the same pipeline in the desktop app, as Python, from a CellProfiler .cppipe, or through a local agent.

How it is built

  1. Check first, then run.

    The pipeline is compiled against your selected wells, sites, channels, and planes before any work starts.

  2. One pipeline, several ways in.

    GUI, Python, and agent all edit the same typed object. Nothing is translated, so nothing is lost.

  3. Say each thing once.

    Each fact lives on the declaration that owns it; every list is derived from those. How.

  4. Fail loudly.

    No silent fallbacks. If OpenHCS can't do what you asked, it says so and says where.

  5. Show the receipts.

    Every figure has a checksum record; the agent run ships uncut with its logs.

  6. Open all the way down.

    MIT licensed, built on libraries you can use on their own.

Installation

Desktop installers No Python needed

Download for WindowsDownload and run — no ZIP to extract Download for macOSOpen the DMG, then open OpenHCS Installer

CPU-only installers that include CellProfiler compatibility, local MCP, Napari, Fiji, and Bio-Formats. GPU libraries are optional and not included. Fiji downloads Java on first use. The latest complete GitHub release may trail PyPI. The Windows installer is unsigned and the macOS installer is not notarized; your OS will ask you to confirm.
