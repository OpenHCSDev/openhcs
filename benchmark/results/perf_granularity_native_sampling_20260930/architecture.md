# Granularity sampling ownership decision

Authorized scope: improve representative single-thread execution and total latency without weakening CellProfiler parity or discrete/error tests. Common timed source fb5fea4f1, after normally integrating PR #259 and PR #205. The measured resampling boundary is 1.381s/well; a saved-input native prototype reduces complete background correction about 0.103→0.021s, enough to plausibly save about one second of the 14.02s pipeline. This is a material measured term, not an inter-step bookkeeping optimization.

NRA 0844525ecaba93e090a064a4ae4914466b2dae60 inventories all 699 Python modules including setup.py. The initial c86f562e1 census contains 5,075 original classes, 5,063 projected and 12 OPEN. The dbf1c7a8b-plus-candidate checkpoint census contains 5,078 original classes, 5,066 projected and the same 12 OPEN: two classes arrived on main and one is the admitted sampling-grid owner. The final fb5fea4f1-plus-candidate census has 5,082 original classes, 5,070 projected and the same 12 OPEN; four further upstream classes arrived in PR #205. The candidate adds only the admitted grid value owner. The compiler class dumps inventory both production C++ sources and their included declarations. Source joins locate OwnedPyObject and CsvScalarNormalization in tabular code, but no existing buffer-lease owner. These are syntax/class inventories and traced source contracts, not all-detector or semantic proofs.

Determining authorities before migration: GranularityImageSeries stores a bare new_shape; background_corrected_pixels, three resample helpers and GranularityLabelPixels.resampled_values independently interpret logical versus physical grids. GranularityReconstructionBackendStrategy owns reconstruction provider selection and preparation. GranularityNativeExtension already owns the stable-ABI native build declaration. Its private module name refers only to reconstruction despite the newly required sampling capability. Existing ResizeGeometry is counterevidence: it uses rounded physical extents, symmetric boundaries and skimage resize semantics, which differ from CP granularity's floating logical extents, ceil-sized origin grids and constant-zero order-one samples. Reusing that policy would change measurements.

Admitted destination relation:

- GranularitySamplingGrid owns the fixed CP logical-grid policy, physical shape projection, subsampling and endpoint coordinate scales. This is one policy/value owner, not an enum/provider family. Image series and label pixels carry that owner; consumers derive scales and dimensions from it rather than storing parallel shape interpretations.
- Dense sampling invokes one installed native operation. Sparse label sampling keeps its existing SciPy point operation but derives its coordinate scales from the same owner. These are distinct physical sampling consumers, not competing grid policies.
- Remove the three obsolete standalone resampling helpers and migrate all production/test consumers; no compatibility aliases or duplicated shape fields remain.
- GranularityNativeExtension determines the renamed _granularity_native module and source path, containing both irreducible reconstruction and sampling kernels. Existing preparation exercises the actual public floating consumers; no new JIT kernel, cache registry, kernel roster or fallback is added.
- Native integer/floating sampling shares a templated numerical algorithm. Python buffer format is an external boundary representation; standard native numeric limits determine casts. Preserve coefficient evaluation order, constant borders, boolean truncation, integer half rounding and actual signed/unsigned overflow behavior. The Numba prototype was rejected after its unsigned cast disagreed with SciPy; the C++ prototype passes all 366 fixtures exactly, including extrema.
- A native buffer lease owns acquisition/release and validation for both native operations. Existing OwnedPyObject owns Python references, not Py_buffer acquisitions, and cannot replace this lease. This is one resource owner with two concrete production consumers, not a second buffer schema.

Required gates remain separate: authored NRA source/syntax transactions and projected census; production dtype/border/nonfinite/endianness and geometry tests; native buffer failure tests; installed wheel/ABI smoke; four saved real inputs and unchanged digests; full ordinary pipeline exports; isolated alternating execution/total observations. A clean recipe is not mathematical or architectural proof. Native casting/source comparison uses SciPy 1.18.1 ni_interpolation.c and ni_splines.c as the primary implementation authority, plus actual local executable fixtures. The native reference timing for future scaling figures remains the earlier physical CP runs with their original limitations.

The public background_corrected_pixels return changes from a pixels/bare-array pair to a pixels/GranularitySamplingGrid pair. GranularityImageSeries and GranularityLabelPixels migrate to that owner; the old new_shape field and standalone helper names are removed. No compatibility alias is kept. Constant-coordinate sampling must mirror the spline footprint at the last cell even though out-of-range coordinates are zero: a clamp prototype failed two complex/nonfinite tests and was rejected. Final tests cover zero-weight NaN/Inf neighbors explicitly. Integer extrema behavior is tested against the actual installed SciPy/compiler combination; it is not a cross-compiler proof of floating-to-integer overflow behavior.

Primary implementation sources: [SciPy 1.18.1 interpolation](https://raw.githubusercontent.com/scipy/scipy/v1.18.1/scipy/ndimage/src/ni_interpolation.c) and [order-one spline coefficients](https://raw.githubusercontent.com/scipy/scipy/v1.18.1/scipy/ndimage/src/ni_splines.c).
