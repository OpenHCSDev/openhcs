# Native measurement assembly and spreadsheet serialization

The current wide imaging-flow producer spends about two seconds exporting 1,800 combined rows / 11,550,064 CSV bytes. Saved current-producer replays, alternating three implementations three times each, measured median whole-export times of 1.934s for Python, 1.802s for native cell assembly, and 1.445s for assembly plus native CSV. Every replay produced the identical recorded SHA256. This is about 25% of export, approximately 0.49s per emitted well; it scales with output cells and does not establish universal workload speedups.

A fresh ordinary `1w_1t` production run measured 3.182s compile, 18.531s execution, 24.433s total, and 1.477s for ExportToSpreadsheet. The prior registry-warming production observation exported in 1.973s. One observation per implementation is not enough to claim a precise total-time percentage. Output bytes and SHA256 match the saved baseline. The existing prepared Numba cache loaded 65 entries and wrote zero; total excludes the earlier 53.529s registry preparation and input staging. This does not close cold compilation (#162), and native CellProfiler was not rerun for this bounded patch.

WideMeasurementRowAccumulator retains row identity, subject/scope ordering, qualifier projection and structural absence. Both wide and scalar assignment use one compiled conflict primitive with the existing Python equality policy. The exporter retains file/subject selection and column discovery, then delegates exact value normalization and quoting. The old Python conflict implementation and `_csv_cell` are retired; native imports are unconditional. One nominal native-extension family derives targets and shares stable-ABI build policy; dependency metadata remains in pyproject.toml.

Validation: 85 focused tests, including 17 new adversarial native-boundary cases, plus 452 broader producer/schema/source-scope/relationship/module/reference/registry tests pass (537 disjoint tests). Tests cover exact standard CSV parity, both dialects/nonfinite modes, NumPy/decimal/fraction values, Unicode subclasses/surrogates/NUL, callback mutation and ordering, partial conflicting assignment, custom mappings and conversion errors. Black and diff checks pass; changed legacy files add no Ruff findings. The release-floor test rejected main's existing native extension declaration before this patch; it now admits build hooks/extensions while retaining its dependency-authority checks.

The final cp311-abi3 Linux wheel loads both native modules in an isolated Python 3.12.14 environment without third-party core dependencies. Strict abi3audit reports zero ABI violations or version mismatches against 3.11. This is not a physical Python 3.11 runtime test. C++ correctness is outside NRA's Python proof scope: global AST/ClassDef inventory, nominal ownership receipt, empirical parity, tests, runtime transfer, wheel loading and ABI audit are separate gates.
