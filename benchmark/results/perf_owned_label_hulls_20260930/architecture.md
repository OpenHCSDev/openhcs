# CP ordered label-hull ownership decision

Delete the full-frame requested-label compaction and the standalone Python CP hull walk. Both circle and illumination now consume CellProfilerLabelHull; raw-label/Feret and requested-ordinal callers share one outline-grouping primitive instead of duplicate loops. No compatibility alias remains.

Context: single-thread execution/total performance, CP numerical/discrete/error parity, current source 295e0ee81 and NRA 0844525e. The original global AST/class-family census covers 699 modules, 5,083 ClassDefs, 5,071 projected declarations and 12 explicitly OPEN rows. Current-main changes since the previous measurement touch output provenance/materialization, not these geometry authorities. The actual circle boundary was captured before prescribing this migration.

The task-authorized relation is exact CP hull ordering and requested measurement-row identity. Existing _compact_requested_labels writes a whole frame to map raw labels to requested row ordinals; _cellprofiler_convex_hull groups outlines and interprets the CP envelope walk. Circle code interprets that tuple, and illumination imports the same hull helper. Native Numba outline grouping is a physical primitive, not another ordering authority. The proposed change must preserve row-major point order, missing/nonpositive/duplicate request positions, sparse IDs, hull vertex order and downstream circles.

Alternative-owner inventory: ObjectLabelDomain owns declared semantic IDs but normalizes/sorts/deduplicates positive IDs, which cannot represent this exact positional CP request contract. RadialLabelGeometry and _ZernikeLabelGeometry hold downstream distances/circle/pixel projections, not ordered hull construction. ConvexHullSmoothingPlaneStrategy and its backend family own level-set image smoothing; FillObjectConvexHullStrategy owns filled object masks. Neither owns shared ordered vertex geometry. The existing monotone Feret hull primitive has a different ordering contract; substituting it can change circle vertex/tie decisions. These are counterevidence to reusing those authorities.

Admit one fixed value/policy owner, CellProfilerLabelHull: label IDs plus grouped outline offsets/coordinates, factories for raw-label hulls and requested-row ordinal hulls, and a shared vertices projection through the exact compiled envelope primitive. There is no behavior-bearing case family here, so no enum, registry, provider roster or nominal leaf hierarchy is introduced. Requested ordinal projection is derived from the caller's existing ordered request, not a second semantic label domain. Counts derive from offsets/kernel output and are not a parallel mutable input field.

Production consumers: enclosing circles and CP convex-hull illumination. Remove full-image compaction and the old standalone hull function; migrate every import/test consumer with no compatibility alias. Raw-label/Feret projection retains its original Numba argsort contract, while requested ordinal projection retains Python NumPy argsort and nonpositive filtering. Both derive sorted labels/output positions for the same numeric grouping primitive. Existing declared Zernike/shape/illumination preparation reaches the real numeric primitives. Numerical kernels remain irreducible array leaves; no new kernel roster, cache authority, persisted store or external format is added.

Evidence before production editing: five saved real 1650x1650 requests have exact ordered hulls, counts, centers and radii. Four alternating replay pairs project about 0.49s/well savings after weighting the repeated frontier; this is not yet an end-to-end claim. Another 480 empty/singleton/thin/random/sparse/reordered/duplicate/nonpositive/missing-ID fixtures match exact ordered arrays. A competing index-queue/boundary-flags reconstruction prototype is exact but saves only about 0.35s across six standalone masks and is deferred. The circle route has the stronger observed payoff and removes an unnecessary whole-frame representation.

Gates remain distinct: exact NRA source/syntax transaction and original-class projection; packaged touched-file structural ratchet/R1 comparison; integer hull/reference fixtures and consumer tests; production saved-input replay; isolated warmed-cache whole-pipeline execution/total A/B; complete export hashes; and updated shared installed/source consumer checks. Syntax/census evidence is not semantic proof. Existing CP tolerances apply to floating outputs; discrete hull/count/error assertions remain exact. Persisted formats are unchanged; removed helper interfaces are internal and reset at cutover.

Maintenance experiment: the sparse/reordered/duplicate/missing-ID case needs no new provider registration, switch arm, or consumer branch. It supplies its label-domain projection to the same grouping/vertices algorithm; an additional geometry consumer calls that owner's projection. This applies the NRA cookbook shared-algorithm principle (example 2) and derived-view principle (example 1) without inventing a behavior family. Neither example justifies introducing an ABC where the domain has only one fixed algorithm. The after census at 37b79f048 contains 5,084 original classes, 5,072 projected and the same 12 OPEN rows; later b856ae561 changes only numeric function bodies/names, not class declarations. No all-detector or global behavioral proof is claimed.
