## Order and coordination

1. Investigate #135's exposed TCP bind and #140's reported unbounded waiter in disjoint worktrees. Both have draft planning PRs, **not fixes**. Preserve actual external transport semantics and reject unsupported claims of equivalence.
2. Trace #133's compile/runtime declaration and #138's benchmark bootstrap independently; do not let #155's reproducibility figures substitute for environment creation.
3. Profile #132's two stages separately. Investigate #131 only with a clean, bounded process baseline, never as a presumed leak.
4. Write a fresh, scoped receipt at dispatch for each remaining surface against that day's main and overlapping PR heads. Run complete contextual NRA analysis where an ownership claim needs it; record `scan_status`, omissions, raw records and OPEN edges. If resource limits prevent it, keep design provisional, do not call the scan complete.

No common new abstraction has yet been justified by multiple verified surfaces. Existing transport endpoints, artifact declarations, viewer lifecycle and status records are *candidates to inspect*, not licenses to create a parallel registry or an all-purpose base class. Each surface owner owns its own PR/worktree and coordinates file crossings directly. Tests protect observable bind, failure, subject, fidelity or benchmark behavior, not an imagined class layout; existing external protocol contracts remain binding.
