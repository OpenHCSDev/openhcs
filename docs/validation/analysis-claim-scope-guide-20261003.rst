Gap and correction
------------------

Existing guidance already requires earliest-stage diagnosis, foreground before
unclumping, ambiguity triage, one semantic change, regression witnesses and
continued development within the authorised resource budget. Those procedures
are not duplicated. The missing instruction was how to scope conclusions when
only some objects or relationships remain unresolved.

The strategy now preserves independently supported claims, records unresolved
cases and exclusions, permits justified bounds/sensitivity analysis, and limits
whole-population claims when the unresolved cases affect them. It neither
certifies completeness from sampled positives nor treats partial support as a
reason to stop repairing a clear failure. Viewer QA links to that single owner
and ties candidate rejection to the requested claim's acceptance criteria.

Custom authoring now requires evidence for actual imports, decorators, helper
types and enum members in the installed version before source submission.
Existing public architecture inspection accepts curated symbol IDs, not arbitrary
import paths. ``InternalApiSymbol`` returns signature/doc/source-location facts,
not complete enum members or source text. The guide does not promise that this
route alone proves a member, invent a reflection endpoint, or copy an enum list.
An unavailable declaration is an exact authoring-contract gap, not evidence that
unrelated scientific outputs are invalid.
