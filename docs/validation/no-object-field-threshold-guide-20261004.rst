Determining source and missing decision
--------------------------------------

The existing guides already cover background patches, distributed bright/dim
and sparse/dense regions, all-foreground threshold units, and near-track nuisance.
They did not explicitly sample a whole apparently no-object field before a first
threshold proposal or widening a positive-only sample. Quiet background inside
a signal-bearing image does not test a per-image estimator when its entire
input contains only background variation.

Read original threshold declarations and implementations:

* ``thresholding_threshold_numba_otsu_histogram_multiotsu._otsu_threshold_numba``
  selects a histogram split by between-class variance. It takes values and bin
  count, not an independently established object-presence fact.
* ``OtsuGlobalThresholdStrategy.compute`` delegates to the declared primitive.
  ``cellprofiler_get_global_threshold`` handles empty/constant inputs separately,
  then dispatches nonconstant values through the existing strategy owner.
  A nonconstant no-object image is not identified as such by this contract.
* ``threshold`` normalizes through the existing CellProfiler image owner;
  ``threshold_min`` is documented in normalized intensity units.
  ``CellProfilerThresholdSettings`` and the global threshold application own
  effective method/correction and final clipping. The guide asks readers to
  reflect that effective contract; source intensity cannot be copied blindly
  onto a processed alias.

Pete Bankhead's existing primary teaching source explains Otsu's class-separation
assumption and foreground partitioning when histogram peaks are not separated:
https://bioimagebook.github.io/chapters/2-processing/3-thresholding/thresholding.html
The no-object interpretation follows that contract and the original source,
not a new detector or a proposed numeric setting.

The addition pairs whole-field raw/processed evidence with genuine dim-positive
and ordinary-positive controls. A measured lower bound is conditional on a
supported callable and comparable acquisition/processing units. Overlapping
distributions or unknown mappings warrant model review/uncertainty, not forcing
blank labels. No dataset identifiers, expected counts, percentile blank rule,
universal cutoff or new tool catalogue is introduced.
